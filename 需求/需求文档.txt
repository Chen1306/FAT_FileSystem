# 简易 FAT 文件系统模拟程序 需求规格说明书

## 1 项目概述

### 1.1 项目目标

本项目模拟实现一个简易文件系统：

1. 使用主机上**单个文件（disk.img，也可命名 disk.txt）模拟整块磁盘**；
2. 使用数组模拟内存缓冲区；
3. 文件逻辑结构：**流式文件**；物理结构：**显式链接（FAT 文件分配表）**；
4. 支持多级目录结构、**绝对路径访问**；
5. 实现文件、目录的各类操作命令；提供命令行交互界面；
6. 编写主函数完成全部功能测试。

### 1.2 运行环境

Windows 平台，编程语言推荐 C / C++ / Java；可使用多线程，可选图形界面，最低要求命令行。

### 1.3 磁盘硬件参数（固定，按文档）

- 模拟磁盘总共有 **128 个物理盘块**
- 每个盘块大小：**64 字节**
- 盘块编号：0 ~ 127
- 盘块 0、盘块 1：存放 FAT 文件分配表（系统占用，不可分配给用户文件 / 目录）
- 根目录固定放在 **盘块 2**
- 每个目录盘块最多存放 8 个目录项；**每个目录项占 8 字节**

## 2 数据结构定义

### 2.1 FAT 文件分配表（文件分配表）

- FAT 共 128 项，**每项占 1 字节**，对应 0~127 号盘块
- FAT 表各项取值含义：

表格

| 值 | 含义 |
| --- | --- |
| 0 | 盘块空闲 |
| 1~127 | 本文件下一个盘块号 |
| -1（实验用 255） | 文件结束标记 |
| 254 | 盘块损坏，不可使用 |

> 
> FAT 第 0 项、第 1 项永久占用，不能分配。

### 2.2 目录项结构（8 字节 / 项，文件、子目录共用）


表格

| 字段 | 长度 | 说明 |
| --- | --- | --- |
| 名称 | 3 字节 | 文件名 / 目录名；首字节 ='$' 代表空目录项；合法字符：字母、数字，不能用`$ . /` |
| 类型保留 | 2 字节 | 文件：存放文件类型；目录：填空格 |
| 属性 | 1 字节 | 位标记：bit0 只读，bit1 系统文件，bit2 普通可读写文件，bit3=1 代表该项是**目录登记项** |
| 起始盘块号 | 1 字节 | 文件 / 子目录对应的第一个盘块号 |
| 保留 | 1 字节 | 文件：文件长度（盘块数）；目录：填 0 |

> 
> 一个盘块 64 字节，`64 / 8 = 8`，所以每个目录盘块最多存 8 个目录项。

### 2.3 已打开文件表（数组模拟，最多同时打开 5 个文件）

```
//读写指针
typedef struct{
    int dnum;    //磁盘盘块号
    int bnum;    //盘块内字节偏移
}pointer;

//打开文件项
typedef struct{
    char name[20];    //绝对路径
    char attribute;   //文件属性
    int number;       //起始盘块号
    int length;       //文件长度
    int flag;         //0读方式打开，1写方式打开
    pointer read;     //读指针
    pointer write;    //写指针
}OFTLE;

//已打开文件登记表
struct{
    OFTLE file[5];
    int length;
}openfile;
```

### 2.4 缓冲区

使用数组 buffer1、buffer2 模拟内存缓冲区；
读写磁盘规则：**以盘块为单位，整块读入缓冲区，修改完成后整块写回模拟磁盘文件，不能一次性加载全部磁盘**。

## 3 功能需求

### 3.1 系统初始化模块

1. 创建 / 打开模拟磁盘文件 disk.img；
2. 初始化 FAT 表：0、1 号盘块标记为占用；其余盘块标记空闲；标记坏块（可选 23、49 号盘块 = 254 损坏）；
3. 初始化根目录（盘块 2），清空目录项；
4. 清空已打开文件表；
5. 初始化缓冲区数组。

### 3.2 目录操作命令

无需用控制台输入，本项目为图形化项目

1. **md（建立目录 create_dir）**
   - 参数：目录绝对路径
   - 逻辑：查找父目录，父目录不存在→失败；父目录存在，检查同名目录，存在则失败；寻找空闲目录项、分配空闲盘块写入目录信息。
   - 限制：只能创建空目录。
2. **dir（显示目录 ls）**
   - 参数：目录绝对路径
   - 逻辑：查找目录，不存在提示失败；遍历目录内全部目录项，输出目录 / 文件名称、属性、大小等信息。
3. **rd（删除空目录 rmdir）**
   - 参数：目录绝对路径
   - 逻辑：不能删除根目录；目录不存在 / 目录非空 → 失败；空目录：删除目录项，回收目录占用盘块，FAT 对应项置 0。

### 3.3 文件操作函数

1. **create_file 建立文件**
输入：文件名、文件属性
   - 校验父目录；同名文件存在则失败；只读属性文件**不允许创建**；找到空闲目录项，分配至少 1 个盘块，写入目录项。
2. **open_file 打开文件**
输入：文件名，操作类型（读 / 写）
   - 文件不存在打开失败；只读文件不能以写方式打开；成功则加入【已打开文件表】；重复打开不重复登记。
3. **read_file 读文件**
输入：文件名、读取字节长度
   - 文件必须已打开，且是读模式；根据读指针从流式文件读取指定字节；读到结束标记`#`终止读取。
4. **write_file 写文件**
输入：文件名、缓冲区、写入长度
   - 文件必须已打开，写模式；仅支持**文件末尾追加写入**；写满当前盘块时自动分配新盘块，更新 FAT 链表。
5. **close_file 关闭文件**
输入：文件名
   - 文件未打开直接返回；写模式关闭时追加文件结束标记`#`；更新目录项；从已打开文件表移除该项。
6. **delete_file 删除文件**
输入：文件名
   - 文件不存在失败；文件已经打开，禁止删除；删除目录项，回收文件所有占用盘块，FAT 全部置 0。
7. **typefile 显示文件内容**
输入：文件名
   - 文件不能处于打开状态；读取文件全部字节，打印文件内容。
8. **change 修改文件属性**
输入：文件名，新属性
   - 文件不存在失败；文件已打开则**不能修改属性**；修改目录项内属性字节。

### 3.4 路径检索规则

- 仅使用**绝对路径**；分隔符`/`；
- 路径检索：从根目录（盘块 2）开始顺序检索目录项；逐层查找子目录直到目标文件 / 目录；查找失败返回错误。

## 4 非功能需求

1. IO 约束：磁盘读写**按盘块为单位**，每次读写一个盘块到缓冲区，修改后写回 disk.img；禁止一次性加载整个磁盘。
2. 错误处理：所有命令要有明确错误提示（文件不存在、权限错误、目录非空等）。
3. 内存约束：最多同时打开 5 个文件。
4. 文件模型：文件是**流式文件**，没有内部记录，读写单位字节。
5. FAT 回收：删除文件 / 目录时，对应盘块 FAT 项置 0，完成空间回收。

## 5 测试需求（主函数）

主程序提供命令循环，接收用户输入指令，依次测试：

1. 初始化文件系统
2. 通过右键目录树创建多级目录、查看目录
3. 右侧右击空白处创建文件、双击空白文件写入内容
4. 右击菜单文件读取、查看文件
6. 右击菜单删除文件
7. 右击目录删除目录，非空文件无法删除
8. 边界测试：满目录、盘块耗尽、非法路径、权限错误等场景

## 6 错误码参考（可选）

0：成功
-1：文件 / 目录不存在
-2：同名对象已存在
-3：权限不允许（只读文件写、打开状态修改属性）
-4：目录非空，无法删除
-5：磁盘无空闲盘块
-6：文件未打开
