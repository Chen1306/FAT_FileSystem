# 简易 FAT 文件系统图形化项目设计说明

## 一、设计目的

本项目设计并实现一个**图形界面版简易 FAT 文件系统**，摒弃传统命令行交互方式，通过可视化图形界面完成文件与目录管理。

1. 模拟磁盘硬件：使用`disk.img`文件模拟磁盘，以盘块为单位对磁盘进行读写操作，设置磁盘缓冲区，理解磁盘缓存工作原理。
2. 实现 FAT 文件管理机制：完成 FAT 表管理，实现磁盘块分配与回收；支持多级目录结构，实现文件、目录的创建、删除、读写、属性修改等基础文件操作。
3. 图形化交互：基于 Swing 实现可视化界面，通过目录树、文件列表、右键菜单完成全部操作，不需要输入命令，直观展示文件系统内部结构。
4. 理解打开文件表（OFT）原理：维护已打开文件表，限制同时打开文件数量，掌握文件打开、关闭的内核管理逻辑。
5. 通过分层设计，将文件系统核心业务逻辑与图形界面解耦，提升代码可维护性，加深对操作系统文件管理模块原理的理解。

## 二、运行环境

1. 操作系统：Windows / Linux / MacOS
2. JDK 版本：JDK 8 或 JDK11（推荐 JDK8，兼容性更强）
3. 开发工具：IntelliJ IDEA / Eclipse
4. 编译运行方式：直接使用 JDK 自带工具编译运行，无需第三方依赖包。

## 三、技术栈

编程语言：Java
GUI 框架：Java Swing（JDK 内置图形组件，无需额外导入 jar 包）
磁盘模拟：`RandomAccessFile`，对`disk.img`镜像文件随机读写，模拟磁盘按块访问。
架构模式：分层架构，分为**文件系统核心层**与**Swing 图形表现层**。

核心 Swing 组件：JFrame 主窗口、JSplitPane 分割面板、JTree 目录树、JTable 文件信息列表、JPopupMenu 右键菜单、JTextArea 日志与文件内容显示区、JOptionPane 弹窗。

## 四、总体设计

### 4.1 总体架构

项目分为两大层次，两层之间低耦合：

1. **文件系统核心层（fs 包）**
不依赖任何 Swing 界面代码，独立实现文件系统所有底层逻辑，可单独测试。

- BootBlock：引导块，保存磁盘基础信息（总盘块大小、盘块尺寸、FAT 起始位置、根目录起始盘块等）。
- FatTable：FAT 表模块，负责磁盘块分配、块回收、坏块标记。
- DirItem：目录项，保存文件 / 目录名称、起始盘块、文件大小、文件属性等信息。
- OFT：打开文件表，记录当前打开文件，控制最大打开文件数量。
- Buffer：磁盘缓冲区，设置缓存块，减少磁盘镜像读写次数。
- Disk：磁盘操作模块，实现`read_block()`读取盘块、`write_block()`写回盘块，操作 disk.img 镜像。
- FileSystem：对外统一接口，封装所有操作方法：创建目录、删除目录、新建文件、打开文件、读文件、写文件、关闭文件、删除文件、修改文件属性。

2. **图形界面层（gui 包）**
负责接收用户操作，展示数据，调用核心层接口，不参与 FAT、目录查找等底层逻辑。

- Main：程序入口类，在 Swing 事件线程中初始化文件系统并启动主窗口。
- MainFrame：程序主窗口，界面布局管理。
- TreeModel：JTree 目录树模型，加载并渲染多级目录。
- FileTableModel：JTable 数据模型，展示当前目录下文件 / 目录信息（名称、大小、起始盘块、属性）。

### 4.2 界面设计

主窗口采用分割面板划分区域：

1. 左侧：JTree 目录树，展示根目录及所有多级子目录，点击切换当前工作目录；目录节点支持右键菜单。
2. 右上区域：JTable 文件列表，展示当前目录下所有文件、子目录信息；文件条目支持右键菜单。
3. 右下区域：JTextArea 文本区域，用于展示文件内容、系统操作日志与错误提示。

右键菜单作为用户唯一操作入口，**不使用命令输入**：

- 目录右键菜单：新建目录、删除目录、刷新目录
- 文件右键菜单：新建文件、打开文件、读取文件、写入文件、关闭文件、删除文件、修改文件属性

### 4.3 核心业务流程

1. 程序启动：初始化 FileSystem，创建或打开 disk.img 磁盘镜像，加载引导块、FAT 表、根目录信息，初始化缓冲区、打开文件表；随后加载主窗口，渲染目录树和文件列表。
2. 用户操作：在目录树或文件列表右键，选择菜单，弹窗接收用户输入（文件名 / 目录名、写入内容等）。
3. GUI 层调用 FileSystem 对应接口，底层执行路径解析、目录查找、FAT 块分配回收、磁盘块读写。
4. 底层返回执行成功 / 失败状态；GUI 刷新目录树、文件列表，并在日志区域输出操作结果。
5. 程序退出：关闭 disk.img 文件，释放资源，退出程序。

### 4.4 主要功能

1. 磁盘模拟：disk.img 模拟磁盘，按盘块读写，设置磁盘缓冲区。
2. 目录管理：支持多级目录，新建目录、删除空目录，目录浏览。
3. 文件管理：新建文件、删除文件；文件打开、关闭、读取内容、写入内容；修改文件属性（普通文件、只读文件）。
4. 打开文件管理：OFT 打开文件表，限制同时打开文件最大数量。
5. 异常处理：捕获各类错误，如磁盘空间不足、删除非空目录、只读文件写入、打开文件超限等，图形界面给出提示。

## 五、运行说明

1. 启动程序，自动初始化 disk.img 磁盘镜像，加载文件系统，弹出图形主界面。
2. 在左侧目录树选择目录，右侧自动刷新当前目录内容。
3. 在目录 / 文件上点击右键，在弹出菜单选择操作，按弹窗提示输入信息。
4. 操作结果会在右下角文本区域输出，文件内容预览同样在此区域展示。
5. 关闭窗口即可退出程序，磁盘镜像 disk.img 会保留本次所有修改。

## 六、设计特点

1. 图形化交互，完全取消命令行输入，所有操作依靠右键菜单触发。
2. 分层解耦，底层文件系统与界面代码分离，底层可独立调试。
3. 严格模拟 FAT 文件系统机制、磁盘块读写、缓冲区、打开文件表，符合操作系统文件系统原理。
4. 使用原生 Java Swing 实现，无第三方依赖，部署简单
